# 금손한의원 공식 블로그 말투

## 조사 범위

- 2026-08-21 네이버 블로그 전체보기에서 공개 글 74편을 확인했다.
- 모바일 원문 URL로 74편 본문을 다시 요청해 74편 모두 읽었다. 실패는 0편이었다.
- 말투 관찰에는 정보글·병원안내·박원장의 생각·개인 기록을 모두 포함했다.
- 자동 생성 대상은 정보글 하나뿐이다. 일상글·공지·업체소개·사례·스토리텔링은 말투 자료일 뿐 생성 유형이 아니다.
- 집계값과 금지 항목은 `assets/goldhand-official-voice-profile.json`을 단일 기준으로 쓴다.

## 말투의 핵심

금손 말투는 단순히 친절한 존댓말이 아니다. 박준희 원장이 실제로 보고 느낀 것을 먼저 말하고, 독자가 겪는 장면을 이어 붙인 뒤, 왜 그런지 설명하는 1인칭 말투다.

1. `제가`, `저는`, `저도`로 원장의 판단을 숨기지 않는다.
2. `치료를 받아도 다시 아프죠?`, `그럴 때 보통 어떻게 하시나요?`처럼 독자에게 바로 묻는다.
3. `사실`, `그런데`, `하지만`, `그래서`로 말을 이어 간다. 교과서처럼 모든 문단을 같은 접속어로 시작하지 않는다.
4. `~습니다`가 기본이지만 `~죠`, `~거든요`, `~더라구요`, `~세요`, `~네요`를 섞어 딱딱함을 푼다.
5. 짧은 단정문 뒤에 실제 동작·생활 습관·진료에서 보는 지점을 구체적으로 설명한다.
6. 치료를 무조건 권하지 않고, 필요 없는 치료를 더하지 않는 태도와 다른 검사가 먼저인 경우를 솔직하게 말한다.

## 이모티콘을 빼도 금손답게 쓰는 법

원문에는 `^^`, `ㅎㅎ`, `ㅠㅠ`, 하트와 이모지가 보이지만 사용자가 모두 금지했다. 이를 제거한 자리를 딱딱한 공문체로 메우지 않는다.

- 이모티콘 대신 원장의 실제 판단을 한 문장 넣는다.
- 감탄 부호 대신 구체적인 경험이나 생활 장면을 넣는다.
- 따뜻함은 `걱정되시죠?`, `저도 그럴 때가 있습니다`, `진료할 때 그 부분을 말씀해 주세요` 같은 실제 대화로 만든다.
- 지원되지 않은 개인 경험은 만들지 않는다. `clinic-facts.md`에 있는 경험만 쓴다.

## AI처럼 보이는 문장

다음은 기존 실패 원고에서 반복된 표현이다. 비슷한 기능의 문장도 피한다.

- `조금 더 분명히 구분할 수 있습니다.`
- `차분히 살펴보겠습니다.`
- `구체적인 단서가 될 수 있습니다.`
- `읽고 나면 무엇을 판단할 수 있는지 알 수 있습니다.`
- `오늘 정리한 두 조건을 차분히 확인해 보시기 바랍니다.`

`판단`, `기준`, `구분`, `확인` 같은 말 자체가 금지는 아니다. 다만 실제로 무엇을 보고 무엇을 할지 없이 이 추상어만 이어지면 실패다.

## 진료실 발화 가능성 검사

금지어 목록을 피하는 것이 목적이 아니다. 모든 문장은 `박준희 원장이 환자를 앞에 두고 실제로 이렇게 말할까?`를 기준으로 검사한다. 문법에 문제가 없어도 입으로 말하면 어색하면 실패다.

다음은 개별 문구가 아니라 전부 같은 실패 유형이다.

- `스스로 운동을 이어가지 마세요`처럼 안전 지시를 번역한 듯 완곡하게 돌려 말하는 문장
- `다시 아파지는 순간을 적어보세요`처럼 독자에게 기록·관찰·회상·정리 숙제를 습관적으로 주는 문장
- 행동 권유 뒤에 `실마리·단서·출발점·첫걸음·길잡이` 같은 추상적 보상을 붙이는 문장
- `몸이 보내는 신호에 귀 기울여 보세요`, `작은 차이부터 살펴보세요`처럼 감성적 여운을 만들기 위한 문장
- 글을 그럴듯하게 끝내기 위해 독자에게 교훈이나 다짐을 요구하는 문장
- `이번 글에서는`, `이 글을 통해`, `함께 살펴보겠습니다`처럼 실제 설명 대신 블로그의 진행을 안내하는 문장
- 필요한 의료 지시를 `~하는 편이 좋습니다`, `~해 보셔도 좋습니다`, `하나의 방법입니다`처럼 지나치게 완곡하게 만들어 의미를 흐리는 문장

안전 경계는 짧고 분명하게 말한다.

- `스스로 운동을 이어가지 마세요` → `혼자 판단해서 운동을 계속하시면 안 됩니다.`
- `무리가 느껴진다면 잠시 쉬어가세요` → `통증이 심해지면 운동을 멈추셔야 합니다.`

진료에 필요한 정보는 목적이 드러나게 말한다.

- `다시 아파지는 순간을 적어보세요. 그게 다음 실마리가 됩니다.` → `언제, 어떤 동작에서 다시 아픈지 진료할 때 말씀해 주세요.`
- `몸의 변화를 차분히 살펴보세요` → `운동 뒤 통증이 더 심해지는지는 확인해야 합니다.`

위 예시는 치환표가 아니다. 같은 생성 원리에서 나온 새 문장도 모두 다시 쓴다. `실제 환자에게 말해도 어색하지 않은가`, `한 번에 뜻을 알아들을 수 있는가`, `왜 이 행동이 필요한지 드러나는가` 세 항목 중 하나라도 아니면 짧고 직접적인 한국어 구어체로 바꾼다.

문장을 부드럽게 만드는 것보다 뜻을 분명히 전달하는 것이 우선이다. 중단해야 하면 `멈추셔야 합니다`, 하면 안 되면 `하시면 안 됩니다`, 진료에 필요한 내용이면 `진료할 때 말씀해 주세요`라고 단정적으로 말한다. 설명이 끝났다는 이유로 교훈·여운·감성 문장을 덧붙이지 않는다.

## 한 문단을 쓰는 순서

1. 독자가 겪는 구체적인 장면을 한 문장으로 꺼낸다.
2. 박 원장의 솔직한 판단이나 진료에서 보는 지점을 붙인다.
3. 원인을 쉬운 말로 설명한다.
4. 꼭 필요할 때만 바로 해야 할 안전 행동이나 의료진에게 말할 내용을 구체적으로 제시한다.

모든 문단이 이 네 단계를 전부 가질 필요는 없다. 문단마다 같은 모양을 반복하면 다시 AI 말투가 된다.

## 레퍼런스와의 분업

- 위석부부한의원 선택 글: 주제, 독자 질문, 핵심 일반 정보, 정보 공개 순서
- 금손 공식 74편: 말투, 화자 거리, 종결어미, 질문 방식, 솔직한 판단 방식
- 금손 사실·카카오톡: 금손의 실제 치료·운영·경력·경험
- `goldhand-naver-native-v4`: 중앙 정렬, 모바일 2~3줄, 네이버 순정 인용구·구분선·표

위석부부한의원의 말투는 사용하지 않는다. 금손의 주제나 업체 사실을 위석 글에서 만들지도 않는다.
