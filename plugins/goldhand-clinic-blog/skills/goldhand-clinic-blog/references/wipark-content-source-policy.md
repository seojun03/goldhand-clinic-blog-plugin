# 위석부부한의원 주제·내용 사용 규칙

## 역할

사용자가 지정한 위석부부한의원 블로그는 글의 `주제와 일반 정보 내용`을 제공한다. 선택한 한 편의 실제 질문과 핵심 정보 순서를 따라야 하며, 제목 장치만 가져와 다른 내용을 쓰면 실패다.

자동 작성에서는 `assets/wipark-content-briefs.json`에 본문까지 검토된 11편만 사용한다. 2024-10-04 이후 다른 정보글을 새로 쓰려면 그 원문을 직접 읽고 같은 형식의 콘텐츠 브리프를 만든 뒤 사용한다.

## 선택한 한 편에서 반드시 가져오는 것

- 제목의 질환·생활 문제 또는 치료·제도 질문
- 도입의 대표 독자 고민
- 원문이 실제로 답한 핵심 일반 정보
- 정보가 공개되는 순서
- 마지막에 회수하는 판단

## 금손 글로 옮기지 않는 것

- 위석부부한의원 상호·지역·원장·경력·학력
- 환자 수·소개율·성과·효과 배수·치료 횟수·회복 기간
- 환자 사례·후기·직접 발화
- Human Anatomy Atlas·EFT 등 금손 자료에 없는 프로그램
- 원문 사진·연락처·지도·예약 링크
- 원문 문장과 비유

## 의료 내용 정리

`wipark-content-briefs.json`의 `orderedGeneralInformation`을 같은 순서로 쓴다. `blockedFromSource`는 삭제하거나 현재 공식 기준과 금손 사실로 안전하게 바꾼다.

보험 횟수·비용·약물 주의사항처럼 바뀔 수 있는 내용은 원문 숫자를 쓰지 않고 발행 시점의 공식 기준을 확인한다. 사용자가 직접 준 금손 사실은 그대로 사용한다.

## 말투 분리

위석 글의 `3분만 집중`, 경력 반복, 치료 결과 단정, 강한 내원 유도는 쓰지 않는다. 완성 문장은 반드시 `references/goldhand-official-voice.md`의 박준희 원장 말투로 다시 쓴다.
